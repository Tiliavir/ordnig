# Unsure files go to `_Prüfen`

Status: Proposed (2026-11-16)

## Decision

Unsure, unreadable, without a year for `{jahr}`, or already filed → `00_Eingang/_Prüfen/` with the reason. A wrong configuration stops the run with all errors listed.

## Why

Nothing is guessed; a misfiled letter is worse than one to look at.
