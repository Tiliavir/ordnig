# 12 Glossary

| Term | Meaning |
| --- | --- |
| Ablage | The archive: one or more mounts below `/ablage`. |
| 00_Eingang | Default inbox folder; new documents of any format. |
| `_Prüfen` | Folder in the inbox for files `sort` did not file, each with a reason in the report. |
| `.ordnig` | State folder in the inbox (rules, cache, logs, lock, version). |
| `regeln.toml` | The owner's rules for `sort`. |
| `{jahr}` | Placeholder for a year folder in a target path. |
| `kopie` | Additional copy of a filed document made by a rule, e.g. in a tax year folder. |
| PDF/A-2u / 2b | Archival PDF; 2u additionally guarantees Unicode text (searchable, copyable). |
| ODF | OpenDocument (`.odt`, `.ods`, `.odp`). |
| Bit rot | Silent change of stored data; found by comparing SHA-256 checksums. |
